# Marginalia for iPhone and iPad

Version 1.1 downloads chapter text directly on your device, keeping the existing design. Read saved text without internet; fetch new chapters with internet and no PC. AI questions, recaps and character analysis use your PC.

See [cloud build instructions](mobile/CLOUD-BUILD.md) and [app usage](mobile/BUILD.md). The build creates an unsigned IPA for personal signing. Requires iOS/iPadOS 17+.

Restart the updated PC reader to enable device-text syncing for AI. The PC library and credentials are not included here.
